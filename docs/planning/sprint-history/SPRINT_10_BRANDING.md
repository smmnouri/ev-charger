# Sprint 10 – Branding

## Status

Completed

## Goal

Align the application branding with the EVCharge identity.

## Branding Decisions

### Official Brand

EVCharge

### Brand Message

شارژ هوشمند، آینده سبز

### Color Palette

Primary:

* Green EV Accent

Secondary:

* Cyan Accent

Background:

* Deep Navy

Text:

* White / Light Gray

### Logo

Selected EVCharge logo adopted as primary brand asset.

Used for:

* Splash Screen
* Authentication Flow
* App Icon
* Profile
* Empty States

### Persian-First Strategy

Application language defaults to Persian.

### Localization

* Persian translations expanded
* Persian terminology reviewed
* RTL support audited

### Number Formatting

Decision:

All user-facing numbers should use Persian digits when Persian locale is active.

Examples:

* ۱,۲۷۳,۰۰۰ تومان
* ۷۸٪
* ۲۴٫۶ kWh

## Result

The application now has a clear visual identity and a consistent Persian-first user experience.
